🌡️ Temperature Monitoring

ระบบตรวจวัดอุณหภูมิด้วย ESP32 CYD และ DHT22

ข้อมูลเบื้องต้น

โครงงานนี้พัฒนาระบบตรวจวัดอุณหภูมิแบบเรียลไทม์ โดยใช้เซนเซอร์ DHT22 ร่วมกับบอร์ด ESP32 CYD เพื่ออ่านค่าอุณหภูมิและนำไปแสดงผล สามารถต่อยอดเป็นระบบ IoT สำหรับบ้าน โรงเรือน ห้องเซิร์ฟเวอร์ หรือห้องปฏิบัติการได้

วัตถุประสงค์

  • ศึกษาการใช้งาน ESP32 CYD
  • ศึกษาการใช้งาน DHT22
  • พัฒนาระบบตรวจวัดอุณหภูมิ
  • แสดงผลข้อมูลแบบเข้าใจง่าย
  • ต่อยอดสู่ระบบ IoT

อุปกรณ์ที่ใช้

ESP32 CYD
DHT22 Sensor
สาย Jumper
USB Type-C

ตัวอย่างอุณหภูมิ

27°C (ตัวอย่าง)

หลักการทำงาน

  1. DHT22 วัดอุณหภูมิ
  2. ส่งข้อมูลไปยัง GPIO27 ของ ESP32 CYD
  3. ESP32 ประมวลผล
  4. แสดงผลบนหน้าจอหรือเว็บ

ประโยชน์

ใช้เฝ้าระวังอุณหภูมิในบ้าน โรงงาน โรงเรือน ห้องเซิร์ฟเวอร์ และใช้เป็นสื่อการเรียนรู้ด้านไมโครคอนโทรลเลอร์และ IoT
